# Code of Conduct

TetherBound Community is intended to be a technically rigorous, welcoming open-source project.

## Expected behavior

Contributors and maintainers should:

- discuss ideas and disagreements on their technical merits;
- be specific, constructive, and respectful in review;
- assume good faith while still reviewing security claims critically;
- make space for contributors with different experience levels and backgrounds;
- avoid harassment, personal attacks, discriminatory language, threats, and unwanted disclosure of personal information;
- never pressure someone to publish credentials, private infrastructure data, exploit details, or other sensitive information in a public thread.

## Security discussions

Potential vulnerabilities and exploit details must follow [`SECURITY.md`](SECURITY.md) rather than being posted publicly before coordinated disclosure.

## Enforcement

Maintainers may edit, hide, lock, or remove content and may restrict participation when behavior materially disrupts the project or creates safety/security risk.

For conduct concerns that should not be public, contact the repository owner privately through an appropriate GitHub channel.
