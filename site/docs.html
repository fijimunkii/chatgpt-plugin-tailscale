Primary external references

TetherBound builds on existing platform security boundaries rather than pretending to replace them. The current design should be read alongside the primary platform documentation:

  • Tailscale SSH — enabling SSH, tag restrictions, SSH policy, and host-key behavior.
  • Tailscale tags — machine identity, tag ownership, and access-control use.
  • Tailscale grants — current policy syntax and additive access semantics.
  • OpenAI Secure MCP Tunnel — the current private MCP connectivity path used by Community.
Claims discipline: the landing site labels implemented features, roadmap features, and validation concepts separately. That distinction should remain release-blocking for all public documentation.
